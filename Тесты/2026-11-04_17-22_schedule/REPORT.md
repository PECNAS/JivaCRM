## КРИТИЧНЫЕ

### C-1. Некорректные даты в ячейках календаря (`data-date`)
Ячейки получают невалидный атрибут даты с отрицательными и несуществующими числами:

```
2026-11--5, 2026-11--4, 2026-11--3, 2026-11--2, 2026-11--1, 2026-11-00
...
2026-11-31, 2026-11-32, 2026-11-33, 2026-11-34, 2026-11-35, 2026-11-36
```

Причина: `renderCalendar()` формирует `dateStr` из `dayNumber` без учёта того, что для пустых ячеек `dayNumber` выходит за пределы месяца, а `String(dayNumber).padStart(2,'0')` даёт `-5`, `00`, `34`.

Последствия: `data-date` используется в контекстном меню (`showContextMenu(e.clientX, e.clientY, dateStr, null)`) — при клике по пустой ячейке передаётся невалидная дата, а затем `openAvailabilityModal(dateStr)` и `create-order` собирают URL с мусорной датой (`create_date=2026-11--5`).

Файл: `static/js/schedule.js:654`

### C-2. На мобильном календарь не помещается в экран и не скроллится
При ширине 390 px:

```
scrollWidth: 390, clientWidth: 390, grid width: 560, cell width: 78.84
```

Сетка шире экрана (560 px), при этом `scrollWidth` документа равен 390 — то есть **горизонтальный скролл заблокирован**, а сетка обрезана. На скриншоте видны только ПН–ЧТ, колонки ПТ/СБ/ВС недоступны, включая 15 ноября с заказами.

Файл: `static/css/schedule.css` (секция мобильной адаптации календаря)

### C-3. Режим «Список» в мобильной вёрстке показывает заголовки таблицы
`order-list-header` присутствует в DOM — на ширине 390 px блок заголовков «Название / Клиент / Адрес / Дата / Стоимость / Менеджер» рассчитан на десктопную сетку и ломает карточную раскладку.

## МАЖОРНЫЕ

### M-1. Сортировка «Клиент (А→Я)» работает неверно
```
sort-date_asc: "Тест | Тест | 15 ноября... | Эмп5"
sort-name_desc: "Тест | Тест | Эмп5 | 15 ноября..."
sort-client_asc: "Тест | Тест | Эмп5 | 15 ноября..."
```

При `client_asc` заказы «Тест» (клиенты Алекс Рожков, Айгуль) стоят перед «Эмп5» (Гульшат) — то есть сортировка по клиенту даёт тот же результат, что и `name_desc`, а не по возрастанию клиента. Значения `a.client` — «Алекс Рожков», «Айгуль», «Гульшат», «Тестовый». Ожидаемый порядок по возрастанию: Айгуль → Алекс Рожков → Гульшат → Тестовый.

## МИНОРНЫЕ

### m-1. Шрифт дат в мобильном календаре 9.6 px
`m-cell-font: "9.6px"` — ниже минимального читаемого размера. Вместе с обрезанной сеткой (C-2) делает календарь на телефоне практически нерабочим.

### m-2. Пустое состояние поиска в календаре не отображается
При поиске несуществующего значения (`абвгд`) в календаре количество событий = 0, но никакого сообщения «Ничего не найдено» нет — пользователь видит пустую сетку и думает, что данных нет или страница сломалась.

```
calendar-empty-search-visible-text: false
```

Файл: `static/js/schedule.js:renderCalendar()` — нет ветки пустого результата.

### m-3. `aria-expanded` не сбрасывается при переключении режимов
`filterToggle.setAttribute('aria-expanded', ...)` меняется только в обработчике клика. При переключении Календарь → Список панель исчезает, но `aria-expanded` остаётся `true`.

### m-4. Двойной клик по полю «Дата» в модалке не открывает inline-редактор
```
dblclick-date-field: "dbl"
inline-input-exists: false
```

Обработчик навешивается, но `startInlineEdit()` не создаёт input. Причина: `canOpenOrders()` (строка 206) не включает роль `boss`, хотя `Employee.can_manage_orders()` для `boss` возвращает `True`. Итог: inline-редактирование даты/адреса недоступно **Боссу**, хотя по правам backend разрешает.

Файл: `static/js/schedule.js:206-213` и `:322`

## ЧТО РАБОТАЕТ

### Календарь
- Отображение месяца, заголовок «Ноябрь 2026», 7 колонок ПН–ВС, 42 ячейки, 30 дней в месяце
- Подсветка текущего дня (`calendar-cell--today`) — ровно 1 ячейка
- Навигация по месяцам: назад/вперёд, переход через границы года (до «Январь 2028»), без ошибок
- Карточки заказов на дате 15.11 отрисованы (2 шт), клик по карточке открывает модалку с полями Название / Статус / Дата / Заказчик / Город / Адрес / Менеджер / Общая стоимость / Услуги
- Баннер «Заказ заполнен не полностью: адрес, время чека, телефон контакта…»
- Закрытие модалки по крестику и по Escape; `body.style.overflow` восстанавливается
- Контекстное меню по правому клику на ячейке: «Создать заказ / Создать тренировку / Отметить занятость / Создать событие»
- Контекстное меню по правому клику на карточке заказа
- Пункт «Отметить занятость» открывает модалку, дата подставляется (`2026-11-15`), список сотрудников загружается (32 записи)
- Поиск в календаре фактически фильтрует события (при открытии панели): «Тест» → 1 событие, «ZZZZ» → 0
- Фильтр статуса влияет на календарь («completed» → 1 событие)
- Переход Календарь ↔ Список без перезагрузки страницы

### Список
- Переключение вида, сохранение выбора в `localStorage` (`jiva_schedule_view = list`), восстановление после перезагрузки
- Заголовки таблицы: «Название | Клиент | Адрес | Дата | Стоимость | Менеджер»
- 4 строки данных, зона заказов без даты отделена
- Сортировка: `date_asc`, `date_desc`, `name_asc`, `name_desc` — применяются
- Фильтр статуса: all=4, request=3, confirmed=0, completed=1
- Поиск без учёта регистра («ТЕСТ» → 3)
- Пустое состояние «Заказы не найдены» отображается
- Чекбокс «Выполненные ранее» сохраняется в `localStorage` (`jiva_schedule_show_past = 1`), бейдж «1» на кнопке «Фильтры»
- Клик по строке открывает модалку заказа
- Закрытие по Escape и по крестику
- `window.refreshSchedule` доступен, автообновление каждые 30 сек зарегистрировано

### Мобильный
- Бургер-меню на месте
- Модалка заказа открывается и читается
- Контекстное меню по долгому нажатию (contextmenu) на ячейке
- Список — карточная раскладка (5 строк текста в карточке)
